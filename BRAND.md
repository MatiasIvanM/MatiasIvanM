# Visual system

One look across the GitHub profile, project repos, and LinkedIn. Neo-retro: functional, intentional, with character, no unnecessary noise.

## Palette

| Name | Hex | Use |
|---|---|---|
| Enamel black | `#17130E` | Backgrounds, plates |
| Cream | `#EFE4CC` | Main text on dark, light backgrounds |
| Burnt orange | `#C8681E` | Accent, shadows, rules. One use per piece. |
| Brass | `#B08D57` | Borders, secondary text |

## Typography

| Role | Font | License |
|---|---|---|
| Display (name, project titles) | Alfa Slab One | OFL |
| Supporting (labels, taglines) | Oswald Medium | OFL |

Display type is used for names only. Everything else in Oswald or the platform default. Text in images is converted to paths so it renders the same everywhere.

## Tone

- Plain verbs, short sentences, active voice.
- A result beats an adjective: "cut release checks from 2 hours to 10 minutes" over "efficient testing."
- No hype. If it is risky or unfinished, say so.
- Same sign-off everywhere: *Quality, purpose, and a bit of gasoline in the veins.*

## Applying it

- **GitHub profile:** `assets/banner.svg` at the top of the README.
- **Project repos:** same banner layout with the project name in place of yours (change the text in `make_banner.py` and re-run).
- **LinkedIn:** banner image exported from the SVG at 1584 x 396 px, headline reusing the line "I build software that holds up when it matters."
